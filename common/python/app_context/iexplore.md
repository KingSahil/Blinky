# Internet Explorer (iexplore.exe)

## Standard Behaviors
- **Legacy Browser**: Internet Explorer is a legacy web browser. Note that it is largely deprecated in favor of Microsoft Edge.
- **Window Management**: Supports standard Windows window controls (Minimize, Maximize, Close) via the title bar or `Alt+Space` menu.
- **History Management**: Browsing history can be managed or cleared via specific shortcuts or the Settings menu.

## Navigation & Shortcuts

### General Navigation
- **Refresh Page**: `F5` or `Ctrl+R`
- **Stop Loading**: `Esc`
- **New Window**: `Ctrl+N`
- **New Tab**: `Ctrl+T`
- **Close Tab**: `Ctrl+W`
- **Switch Tabs**: `Ctrl+Tab` (next) or `Ctrl+Shift+Tab` (previous)
- **Navigate Back/Forward**: `Alt+Left Arrow` / `Alt+Right Arrow`

### Menus & Dialogs
- **Organize Favorites**: `Ctrl+B` (Opens the Organize Favorites dialog)
- **Search Bar**: `Ctrl+E` (Focuses the search/address bar)
- **Find on Page**: `Ctrl+F`
- **Delete Browsing History**: `Ctrl+Shift+Delete`
- **Title Bar Menu**: `Alt+Space` (Accesses system menu for Move, Size, Minimize, Maximize, Close)

### Help & Support
- **Help**: `F1` (Opens the Help and Support window)
- **About Internet Explorer**: Accessible via the Tools menu (gear icon) or `Alt+X` then `A` (if menu bar is visible).
