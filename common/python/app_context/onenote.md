# OneNote (onenote.exe)

## App Overview
OneNote is a digital notebook application for Windows 10 and 11, allowing users to organize notes, drawings, and files. The current window title suggests a specific notebook or section is open.

## Standard Behaviors
- **Notebook Structure**: Content is organized into Notebooks > Sections > Pages.
- **Syncing**: Changes are typically synced to the cloud (OneDrive) automatically.
- **Formatting**: Supports rich text, handwriting, and multimedia embedding.

## Navigation & Shortcuts
- **Open Settings**: Click the **File** tab (or press `Alt + F`), then select **Options** or **Account**.
- **Access Help/Support**: Click the **File** tab, then select **Help** or **Support**.
- **New Page**: Press `Ctrl + N` or click the **New Page** button in the Home ribbon.
- **Search**: Press `Ctrl + F` to search within the current notebook.
- **Navigation Pane**: Use the left-hand pane to switch between Notebooks and Sections. Click the **Home** icon to return to the start page.
