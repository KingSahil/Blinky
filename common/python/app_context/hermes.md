# Hermes Desktop Assistant Guide (hermes)

This guide summarizes the standard behaviors and navigation points for the Hermes desktop application.

## 🚀 Core Functionality & Behaviors

*   **Interaction:** The app provides a polished experience for chatting with the AI, featuring streaming tool output and side-by-side previews.
*   **Automation:** Hermes Agent can drive your desktop in the background (clicking, typing, scrolling) without moving the visible cursor.
*   **Features:** Key integrated features include a file browser, voice input/output, cron scheduling, profiles management, and skills integration.

## ⌨️ Navigation & Shortcuts

*   **Command Palette:** Access core functions quickly by pressing **`Ctrl+K`** (or `Cmd+K` on macOS).
*   **General Navigation:** The application supports comprehensive keyboard shortcuts for a native desktop feel. (Users should check the in-app settings or documentation for the full list.)

## ⚙️ Key Areas & Settings

*   **Settings/Configuration:** Access configuration options, which may involve setting API keys (`.env`), managing OAuth credentials, or configuring custom endpoints via `config.yaml`.
*   **Agent Control:** Utilize dedicated surfaces for multi-agent work, including the **Command Center** and management of various **Agents**.

## 💡 Quick Tips

*   For advanced setup, review documentation regarding authentication methods (API key vs. OAuth).
*   The app is available across macOS, Windows, and Linux.
