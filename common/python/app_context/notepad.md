# Notepad (notepad.exe)

## App Overview
- **Process**: `notepad.exe`
- **Window Title**: `untitled - notepad`
- **Type**: Basic text editor for Windows.

## Standard Behaviors
- Opens with a blank, untitled document.
- Supports standard text editing (copy, paste, cut, undo, redo).
- Minimalist interface with a single menu bar and status bar.

## Navigation & Shortcuts

### Menu Bar Access
- **File**: New, Open, Save, Save As, Page Setup, Print, Exit.
- **Edit**: Undo, Redo, Cut, Copy, Paste, Find, Replace, Go To, Select All, Time/Date.
- **Format**: Word Wrap, Font.
- **View**: Zoom, Status Bar.
- **Help**: About Notepad.

### Common Keyboard Shortcuts
- **Ctrl + N**: New file
- **Ctrl + O**: Open file
- **Ctrl + S**: Save file
- **Ctrl + P**: Print
- **Ctrl + F**: Find
- **Ctrl + H**: Replace
- **Ctrl + A**: Select All
- **Alt + F**: Open File menu
- **Alt + E**: Open Edit menu
- **Alt + H**: Open Help menu

## Notes for Blinky
- This is the standard Windows Notepad, not Notepad++. Do not confuse with advanced features like tabs or syntax highlighting.
- Use the **Help** menu for version info and basic support.
- For accessibility, ensure the **Status Bar** is visible (View > Status Bar) to monitor line/column position.
